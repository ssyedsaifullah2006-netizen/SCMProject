# Campus Care Connect

Build a full-stack Campus Complaint & Maintenance System (CCMS) with a modern responsive frontend and functional backend.

Frontend: React + Tailwind CSS with pages for Login, Dashboard, Register Complaint, My Complaints, Complaint Details, Technician Dashboard, Estate Manager Dashboard, Admin Panel, and Notifications.

Backend: Node.js + Express + PostgreSQL. Implement authentication, role-based access (Student/Faculty, Technician, Estate Manager, Admin), complaint CRUD operations, technician assignment, status updates, photo upload, notifications, and dashboard statistics.

Complaint flow:

Registered → Assigned → In Progress → Resolved → Closed

Create proper database tables for Users, Complaints, Categories, Locations, Technicians, Assignments, Notifications, and Complaint Updates.

Use realistic campus data, secure API endpoints, form validation, error handling, and connect the frontend completely to the backend. Make all forms, buttons, dashboards, and status updates functional.
